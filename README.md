# BetterThrowing

Throw assist for **BRUTALISTICK VR** (MelonLoader, IL2CPP).

Aims your throws at the enemy you are throwing at, makes weak throws reach, and keeps spears and knives flying tip-first.

- Thunderstore package files: [`thunderstore/`](thunderstore)
- Changelog: [`thunderstore/CHANGELOG.md`](thunderstore/CHANGELOG.md)

## Install

1. Install MelonLoader 0.7.3 for BRUTALISTICK VR.
2. Copy `BetterThrowing.dll` into `Mods`.

## Build

```
dotnet build -c Release -p:GameDir="D:\SteamLibrary\steamapps\common\BRUTALISTICK VR"
```

Build the Thunderstore zip with `.\package.ps1`.
