# Throw Assist — журнал мода

Мод для BRUTALISTICK VR: помогает попадать брошенными предметами по живым врагам и манекенам.
Написан с нуля, старый ThrowAimAssist не использовался.

## v1.5.1 — переключатель броска врагов

Брошенное тело врага тоже получало импульс: оно приходит через тот же `Released`, что и предметы.
Добавлен `AssistRagdolls` (по умолчанию `true` — поведение как в 1.5.0). При `false` тела с
`ActiveRagdoll.StickHealth` в иерархии пропускают ассист и летят обычной физикой.

## v1.5 — копья без MeleeWeaponWrapper

Проблема: Naginata попадала остриём, а остальные копья виляли и влетали плашмя. Причина — разворот
наконечника включался только при наличии `MeleeWeaponWrapper` с типом `Sharp`. У копий-пропов
обёртки нет, поэтому они летели с вращением, которое им дала рука.

1. **Наконечник без обёртки.** Если обёртки нет, предмет проверяется по геометрии: коллайдеры
   вытянуты (длина ≥ 0.6 м и ≥ 4 толщин) — это копьё/шест. Наконечник — дальний от руки конец
   длинной оси. Разворот и удержание включаются и для таких предметов.
2. **Удержание дольше.** Ось наконечника хранится в локальных координатах тела, фиксация теперь
   2.5 с вместо 1.2 — долгий бросок успевает долететь, а не заканчивается за полпути.
3. Оружие с обёрткой работает как раньше: `stabColliders` → `bladeColliders` → все коллайдеры.

Нож, топор и молоток под геометрию не попадают (у них отношение длины к толщине меньше 4), их
ориентация не трогается.

## v1.4 — без головы для лезвий, ровнее копья, больше скорости

1. **Тело по `AimAtHead`.** Автоопределение лезвийного оружия убрано: как и оказалось в игре,
   тип оружия ненадёжен. При `AimAtHead = false` бросок идёт в грудь (`upperChest`), а если
   груди нет — в живот (`pelvis + 0.9 м`). В руки и ноги мод не целится вообще.
2. **Ровный полёт для всех.** `SolveStraight` теперь применяется к каждому броску, а не только
   к распознанному острому оружию. Копья больше не зависят от того, нашёлся ли `MeleeWeaponWrapper`:
   подъём над прямой ограничен `Arc` (8°), на 20 м получается ~9° из-за потолка 30 м/с.
   Дуга стала одинаковой от броска к броску.
3. **Скорости по уровням.** 1: 10 м/с, 2: 13, 3: 17, 4: 22 (как было), 5: 27 — новый уровень,
   угол захвата 85°. Плюс `SolveStraight` сам разгоняет бросок до нужной прямоты, поэтому
   на средней дистанции все уровни стали заметно быстрее.

## v1.3 — тело для лезвий и прямой полёт копий

1. **Острое оружие всегда целится в тело.** Ножи, копья, мечи и прочее Sharp больше не
   наводятся в голову: `AimAtHead` на них не действует, удар идёт в грудь (`upperChest`).
   Площадь тела больше — промахов меньше. Тупое оружие по-прежнему летит в голову.
2. **Копья летят прямо.** `Ballistics.SolveStraight` для Sharp разгоняет бросок, пока угол
   подъёма над прямой до цели не станет ≤ `SharpArc` (8°). Если прямее не выходит — берётся
   самый плоский вариант в пределах `MaxSpeed` (30 м/с), а не отказ. На 10 м это ~7°, на 20 м
   ~9°: дуга почти незаметна, попадание сохраняется.
3. **Стабильная версия 1.2.0** сохранена: `releases/ThrowAssist-1.2.0.zip`
   (исходники, csproj, MODLOG и DLL 1.2.0).

## v1.2 — уровни ассиста и фиксация острия

1. **Уровень ассиста.** `AssistLevel` 1..4 (0 — свои старые настройки). 2 = то, что было раньше
   (средний). 3 и 4 заметно агрессивнее: шире угол захвата и выше минимальная скорость полёта.
   Уровни задают угол/силу/скорость сами, `MaxAngle`, `Strength` и `MinAimSpeed` работают только
   при `AssistLevel = 0`.
2. **Слабый бросок.** Теперь скорость меряется не только у тела: пока предмет в руке, мод каждый
   кадр считает скорость кисти. Если HVR в обычном времени отдал телу меньше `MinThrowSpeed`, но
   рука шла быстрее `HandThrowSpeed` (2.5 м/с) — это всё равно бросок, и направление берётся
   у руки. После применения скорость удерживается ещё 3 кадра, если игра перезапишет её своей.
3. **Сопротивление среды.** `Ballistics.Solve` учитывает `Rigidbody.drag` (формула с экспонентой),
   поэтому бросок не недолетает из-за трения. При drag = 0 результат прежний.
4. **Копьё/лезвие.** Точка острия берётся сначала из `stabColliders`, потом из `bladeColliders`,
   и только потом из всех коллайдеров. После разворота остриё удерживается по направлению полёта
   1.2 с: угловая скорость каждый кадр подтягивает ось к вектору скорости (без кувырка).

## v1.1 — по отзыву с игры

1. **Слабый полёт в обычном времени.** Slow-mo раздувает скорость руки, поэтому в обычном времени
   бросок слабее. Добавлен `MinAimSpeed` (8 м/с по горизонтали): слабый бросок всё равно летит
   с этой скоростью и достаёт цель. Плюс ассист теперь ждёт 2 кадра после отпускания, чтобы HVR
   успел выставить свою скорость, и только потом читает её.
2. **Удар о коллизию руки.** Сразу при отпускании столкновения брошенного предмета с коллайдерами
   кисти/предплечья игрока (в радиусе 20 см от руки) отключаются на 0.3 с, потом возвращаются.
   Это убирает подлёт/сбивание траектории.
3. **Оружие по типам.** У оружия с `MeleeWeaponWrapper` читается `meleeWeaponSO.meleeWeaponType`.
   Для `Sharp` (ножи, копья, лезвия) предмет разворачивается самой дальней от руки точкой
   (остриём/лезвием) по траектории, а кувырок гасится — остаётся только вращение вокруг оси полёта.
   Для `Blunt` ориентация не трогается, цель — голова (`AimAtHead`).

## Как работает

1. Мод находит все `HVRGrabbable` в сцене (раз в 2 с) и подписывается на `Released`.
2. После отпускания ждёт, пока тело перестанет быть kinematic (до 0.25 с), и читает `rb.velocity`.
3. Если скорость меньше `MinThrowSpeed` — это не бросок, а выронил, ничего не делает.
4. Из рагдоллов (`StickHealth`) выбирает ближайшего по углу к направлению броска
   (в пределах `MaxAngle` и `MaxDistance`), целится в голову (jaw) или грудь (upperChest).
5. Считает точную баллистику при постоянной гравитации: полёт T = горизонт. дистанция /
   горизонт. скорость, вертикаль = dy/T + 0.5·g·T. Скорость игрока по горизонтали сохраняется,
   но T ограничен 3 с, поэтому вдаль бросок чуть ускоряется.
6. Делает одну поправку на движение цели (упреждение по `pelvisRb.velocity`).
7. Смешивает исходную и идеальную скорость по `Strength` и ставит один раз. В полёте мод
   тело не трогает.

Если для попадания нужна скорость выше `MaxSpeed` (30 м/с), бросок не меняется.

## Настройки (UserData/MelonPreferences.cfg, категория ThrowAssist)

| Ключ | По умолчанию | Смысл |
|---|---|---|
| Enabled | true | включить мод |
| AssistLevel | 2 | 1=слабый, 2=средний, 3=сильный, 4=максимальный, 5=экстрим, 0=ручные настройки |
| Strength | 1.0 | только для уровня 0. 1 = точно в цель, 0.5 = половина поправки |
| MaxAngle | 35° | только для уровня 0. Угол от направления броска, в котором ищется цель |
| MaxDistance | 20 м | дальность поиска цели |
| MinThrowSpeed | 3 м/с | медленнее считается «выронил» (если рука тоже медленная) |
| HandThrowSpeed | 2.5 м/с | скорость кисти, при которой отпускание всё равно считается броском |
| MinAimSpeed | 8 м/с | только для уровня 0. Минимальная скорость полёта |
| MaxSpeed | 30 м/с | предел скорости, который мод готов выдать |
| AimAtHead | true | целиться в голову; false — в грудь/живот, в руки и ноги мод не целится |
| BladeFirst | true | оружие Sharp разворачивается лезвием/остриём по траектории |
| Arc | 8° | допустимый подъём броска над прямой до цели; меньше — прямее и быстрее |
| IgnoreUnconscious | false | не помогать по лежачим без сознания |
| Log | false | строка в Latest.log на каждый подправленный бросок |
| AssistRagdolls | true | помогать броскам врагов: выключи — тело полетит обычной физикой |

## Проверка

- `dotnet build -c Release` — 0 ошибок, 0 предупреждений (net6.0, ссылки на Il2Cpp-сборки игры).
- `dotnet run` в `tests/BallisticsCheck` — математика проверена симуляцией полёта, все проверки прошли.
- В игре: бросить нож/бутылку в манекен с 5–10 м, включить `Log` и смотреть `MelonLoader/Latest.log`.
- Ожидаемо: без цели в конусе броска поведение не меняется; за стеной цель не проверяется (нет raycast).

## Ограничения v1

- Нет звука/хаптики/подсветки — подтверждение только по логу.
- Нет проверки линии видимости: мод может «помочь» в цель за тонкой стеной.
- Цель выбирается по направлению броска, а не по взгляду.
- Упреждение одношаговое, для очень быстрых целей возможен небольшой недолёт.
